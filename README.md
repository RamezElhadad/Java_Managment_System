# Java Management Systems

A collection of Java applications developed during my studies in Spain, demonstrating object-oriented programming, database integration, desktop GUI development, and file handling.

The project includes a student administration application and a graphical employee and department database management application.    

The Code is written in Spanish.

## Technologies Used

- **Java** — Application development and object-oriented programming
- **Java Swing / AWT** — Desktop graphical user interfaces
- **MySQL** — Relational database management
- **JDBC** — Java-to-database connectivity
- **Java I/O** — File reading and writing
- **Java Serialization** — Saving and restoring Java objects

## Features

### Student Administration

- Add and remove student records
- Modify student information
- Store student contact information and academic grades
- Calculate final grades from evaluation scores
- Display student information
- Write student records to text files
- Demonstrate object serialization and deserialization

### Employee & Department Management

- Graphical interface built with Java Swing
- Manage employee and department records
- Insert, delete, and update database entries
- Retrieve and display database records
- Select specific fields for modification
- Connect to a MySQL database using JDBC

## Project Structure

The source code is organized into two Java packages:

**`e` — Student Administration**

Contains the `Alumno`, `Administracion`, and `ExcerciseStream` classes.

**`guiParte` — Database Management GUI**

Contains `Ventana1`, `Opciones`, `Info`, `DB`, and `Finale`.

## Technical Concepts Demonstrated

- Object-oriented design and encapsulation
- Collections and data management
- CRUD operations
- SQL database connectivity
- Event-driven programming
- File I/O and object serialization
- Desktop user-interface development

## Development Status

Academic project originally developed in Spain. Further improvements are planned for database configuration, input validation, error handling, and application portability.
